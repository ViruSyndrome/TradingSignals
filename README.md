# Trading Signals

A multi-purpose cryptocurrency trading-signal platform consisting of a static web dashboard and a Telegram alert bot. 

Both the dashboard and the bot share a single, mathematically identical technical analysis (TA) engine. This ensures that the signals, scores, and confidence percentages you see on the dashboard perfectly match the alerts generated by the backend bot.

## Architecture

The project relies on a "shared-engine" pattern:
- **`js/indicators.js`**: Pure mathematical implementations of RSI, MACD, Bollinger Bands, EMA, SMA, and ATR.
- **`js/signals.js`**: The composite scoring engine. It takes OHLCV arrays, applies the indicators, incorporates the Global Fear & Greed index, and outputs a directional signal (`STRONG_BUY`, `BUY`, `NEUTRAL`, `SELL`, `STRONG_SELL`) along with a confidence percentage.
- **`js/config.js`**: Global configuration governing the asset universe, fetch limits, and the "Proven Winners" filter.

### Consumers
1. **Frontend Dashboard (`index.html`)**: Fetches data from Binance using `js/api.js`, passes it to the shared engine, and renders the responsive UI.
2. **Telegram Bot (`bot.js`)**: Runs via Node.js on a server/cron, fetching Binance data directly, processing it through the exact same shared engine, and sending mobile alerts.
3. **Backtester (`backtest.js`)**: A strict walk-forward, cost-sensitive historical backtesting suite used to validate the engine's edge and generate the `provenWinners` list.

## Setup & Execution

### Dashboard
The dashboard is entirely static frontend HTML/JS/CSS.
1. Serve the directory using any static web server (e.g. `npx serve .` or host on Netlify).
2. Open `index.html`.

### Telegram Bot
The bot requires Node.js.
1. Run `npm install` to install dependencies (`node-telegram-bot-api`, `dotenv`).
2. Copy `.env.example` to `.env` and insert your Telegram Bot Token and Chat ID. Set `TELEGRAM_POLLING=true` only on the single deployment that should receive `/start`, `/buy`, `/sell`, and `/status` commands.
3. Run `node bot.js` to start the bot.

## Validation & Testing

Run `node backtest.js --walk-forward-rolling` on the 1st of every month to re-validate the `provenWinners` core list.

Run `npm test` to run the mathematical integrity tests on the technical indicators.
